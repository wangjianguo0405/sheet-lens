# SheetLens

[English](README.md) | [简体中文](README.zh-CN.md) | **日本語**

高速でローカル完結の Excel ビューアです。ブックを開けば、Excel が表示する内容がそのまま見えます — Excel を待たずに。

Tauri 2、Rust（セル値の読み取りに [calamine](https://github.com/tafia/calamine)）、React 19 + Tailwind で作られています。グリッドは表計算ライブラリを流用せず自前のレンダラで、ブックの XML を直接読んでレイアウト — 列幅、行の高さ、セル結合、罫線、塗り、フォント、印刷範囲、そしてセルの上に浮かぶ図形や画像 — を取り出し、Excel の描画結果をキャンバスに描画します。

`xlsx`、`xlsm`、`xls`、`xlsb`、`ods` を開けます。旧形式には読むべき zip がないため、既定のスタイルにフォールバックします。

## できること

- シート一覧、検索、ジャンプ、列フィルタ、数式バー
- ファイルメニュー：ブックを開く、最近開いたブックから開く、表示中のブックを閉じる。最近の一覧から項目を削除することもできます。タブは中クリックでも閉じられます
- セル・行/列・矩形範囲の選択。ドラッグのほか、Shift + 方向キーでも拡張できます。Ctrl+A はカーソル周辺のデータ範囲、もう一度押すとシート全体
- Excel 自身の形式での Ctrl+C コピー（列はタブ区切り、行は改行区切り）
- Ctrl+ホイールでのズーム。Excel と同じ段階で、右下に同じコントロール
- セルの上に浮かぶ図形と画像：吹き出し、コネクタ、中括弧、グラデーション。逆解析ではなく ECMA-376 のプリセット図形定義表から描画
- 印刷範囲を改ページプレビューと同じ見え方で：範囲外の網掛けと、境界の太い青い罫線
- 結合セル、空いた隣接セルへの文字のあふれ、インデント、そして共有辺の罫線を Excel と同じ規則で解決

## 実行

```bash
pnpm install
pnpm tauri dev                   # 開発（ホットリロード付き）
pnpm tauri build --no-bundle     # ポータブル exe は src-tauri/target/release に出力
```

## テスト

```bash
cd src-tauri && cargo test
```

テストは `samples/sample-design.xlsx` に対して実行します。パーサを鍛えるために作った合成ブックで、4 枚のシート、結合されたタイトル、明示的な列幅、オートフィルタ、罫線、塗り、配置とインデント、そしてページング用の 12,000 行シートを含みます。

無視（ignored）された 2 つのテストは、代わりに手元のブックを読みます。実在する文書でパースを確認する唯一の方法です。

```bash
SHEETLENS_XLSX="/path/to/book.xlsx" SHEETLENS_SHEET="Sheet1" \
  cargo test --release profile_switch -- --ignored --nocapture
```

## Excel との一致をどう確認するか

Excel そのものと、実際の文書で突き合わせます。

- `Shape.CopyPicture` は Excel 自身の描画結果をクリップボードに載せます — ビットマップ、または図形を選択していれば実際のパスコマンドを含む SVG。吹き出しや中括弧が*どう見えるべきか*を知る最短の手段です。
- `ExportAsFixedFormat` は印刷範囲をベクタ PDF に書き出します。
- ignored の dump テストは、各シートの図形・アンカー・色、あるいは図形の解決済みの幅と位置を出力します。差異を推測ではなく数値として読めます。
- 開発ビルドでは `Ctrl+Shift+D` が同じ解決結果を画面に出します。シートのフォントと実測の数字幅、既定の列幅と行の高さ、選択セルの解決済みスタイルと罫線、そして各図形の枠です。

これが難しいのは、Excel のレイアウト単位が Excel 独自だからです。列幅はブックのフォントの最大数字幅の倍数 — 游ゴシックなら 8px、Calibri なら 7px — で、どちらなのかはファイルのどこにも書かれていません。行の高さはポイント、セルの余白も同じ数字幅から導かれます。
