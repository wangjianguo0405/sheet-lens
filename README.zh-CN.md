# SheetLens

[English](README.md) | **简体中文** | [日本語](README.ja.md)

快速、本地优先的 Excel 查看器。打开工作簿就看到 Excel 会显示的内容——不用等 Excel。

基于 Tauri 2、Rust（单元格取值用 [calamine](https://github.com/tafia/calamine)）和 React 19 + Tailwind。网格是自己写的渲染器，而不是套用某个电子表格库：它直接读工作簿的 XML 还原布局——列宽、行高、合并、边框、填充、字体、打印区域，以及浮在单元格上方的形状和图片——再把 Excel 的渲染结果绘制到画布上。

`xlsx`、`xlsm`、`xls`、`xlsb`、`ods` 都能打开；旧格式没有 zip 结构可读，因此退回默认样式。

## 能做什么

- 同时打开多个工作簿，每个是一个标签页：拖动换位，中键或右键菜单关闭；文件菜单从最近打开里再开一个，起始页固定你常用的工作簿和文件夹
- 自带的文件夹树，可以在网格旁，也可以在起始页：逐级展开文件夹，按名字跨所有根目录查找，点一下打开工作簿
- 工作簿的工作表列表：隐藏和固定的工作表、标签颜色、隐藏与取消隐藏，以及两端带「…」的工作表标签条
- 工作簿搜索、跳转、列筛选和公式栏
- 单元格、整行/整列、矩形区域选择：可以拖动，也可以用 Shift 配方向键扩展；Ctrl+A 选中光标周围的数据区，再按一次选中整张表
- Ctrl+C 按 Excel 自己的格式复制：列间用制表符，行间用换行
- 功能区格式编辑——字体、字号、粗体/斜体/下划线、对齐、填充与字体颜色、冻结与拆分——只在本次会话有效，从不写回文件
- 冻结窗格与 Excel 的拆分视图；每个工作表都在文件留下的位置打开
- 条件格式、批注、数据验证列表、分级显示分组，按 Excel 的画法呈现
- Ctrl+滚轮缩放，走 Excel 自己的档位，右下角有它那个控件
- 单元格上方的形状和图片：标注、连接线、花括号、渐变——按 ECMA-376 的预设几何表绘制，而不是逆向猜出来的
- 打印区域按分页预览的样子呈现：区域外着色，边界上那条粗蓝线
- 合并区域、文字溢出到空的邻格、缩进，以及按 Excel 的方式裁决共享边上的边框
- 英文、中文和日文界面——默认跟随系统，可在应用里切换
- Windows 绿色版，从签名的发布包自更新

## 运行

```bash
pnpm install
pnpm tauri dev                   # 开发，带热重载
pnpm tauri build --no-bundle     # 绿色版 exe 输出到 src-tauri/target/release
```

## 测试

```bash
cd src-tauri && cargo test
```

测试套件跑的是 `samples/sample-design.xlsx`，一个为压解析器而造的合成工作簿：四个工作表、一个合并标题、显式列宽、自动筛选、边框、填充、对齐与缩进，外加一张 12,000 行的工作表用来测分页。

另有七个 ignored 测试改为读你自己机器上的工作簿（`SHEETLENS_XLSX`）——这是拿真实文档验证解析的唯一办法：profile 切换、长工作表的行样式、富文本、图形、条件格式，以及两个 dump（浏览器夹具和单元格边框）。

```bash
SHEETLENS_XLSX="/path/to/book.xlsx" SHEETLENS_SHEET="Sheet1" \
  cargo test --release profile_switch -- --ignored --nocapture
```

## Excel 还原度是怎么验的

对着 Excel 本身、在真实文档上验：

- `Shape.CopyPicture` 会把 Excel 自己的渲染结果放进剪贴板——位图，或者是选中形状时带真实路径命令的 SVG。这是看一个标注或花括号*应该*长什么样最快的办法。
- `ExportAsFixedFormat` 把打印区域输出成矢量 PDF。
- ignored 的 dump 测试会打印每张表的形状、锚点与颜色，或者某个形状解算出的宽度和位置，于是差异可以当数字读，而不是靠猜。
- 开发构建里 `Ctrl+Shift+D` 会在屏幕上给出同一批解算结果：工作表的字体与实测数字宽度、默认列宽行高、选中单元格解算出的样式与边框，以及每个形状的框。

这件事难，大半是因为 Excel 的布局单位是它自己的。列宽是工作簿字体最大数字宽度的倍数——游ゴシック 是 8px，Calibri 是 7px——而文件里没有任何地方记录是哪一个；行高是磅；单元格的内边距也由同一个数字宽度推出来。

## 未实现

书签、两个工作簿之间的对比。线程化批注和旧式 VML 表单控件不读——Excel 存在 VML 里的旧式批注是会读的。预设表里没有的形状，或路径用了渲染器不支持的命令，退回矩形。WMF 和 EMF 图片完全画不出来。
